# 노션 문서에 한 번에 반영할 것 (2026-10-27 기준)

## 운영자 API (B안) — 기능명세서 · API 명세서 · ERD
- API 명세서: 새 절 "운영자 API" — `POST/GET /api/admin/notices`, `DELETE /api/admin/notices/{id}`, `POST/GET/DELETE /api/admin/tours`
  - 인증 `Authorization: Bearer <ADMIN_TOKEN>` (가이드 접근 코드와 별도), 꺼져 있으면 403, 토큰 틀리면 401
  - 입력자 `X-Admin-Name` 헤더 (선택, 영문). 중복 원문 URL 409. 지난 날짜 일정 400. 같은 시각 재입력은 길이만 갱신
  - 요청 제한 IP당 분당 30회
  - 에러 코드표에 409 추가, 엔드포인트 개수 13 → 19
- ERD: `notice.created_by`, `tour_schedule.created_by`, `tour_schedule.created_at` 추가. tour_schedule·notice "쓰는 쪽"을 관리자 API로
- 기능명세서: 범위 표 "관리자 화면"은 그대로 범위 밖, 대신 "운영자 API(화면 없음, /api/docs 사용)" 추가. T-30·T-50 실제 구현의 입력 방법 갱신. 17-x에 "관리자 토큰 운영(누가 갖나)" 추가. ERD E6 일부 해소
